# Neurogenesis_ODE_Models_Webapp

A webapp that allows users to modify parameters of and run the ODE models of Drosophila neurogenesis described in our preprint [Altering cell size asymmetry in Drosophila neural stem cells creates supernumerary stem cells with limited lineage expansion potential](https://www.biorxiv.org/content/10.1101/2025.09.26.678890v1).
